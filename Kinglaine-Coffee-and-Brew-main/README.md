# Kinglaine Coffee & Brew

## User Manual

### Overview

Kinglaine Coffee & Brew is a responsive coffee shop website designed to provide customers with an interactive and convenient online ordering experience. The system allows users to browse products, customize beverages, manage their shopping cart, and view loyalty rewards.

---

## System Features

### 1. Home Page

The Home Page serves as the landing page of the website and provides:

* Featured coffee promotions
* Popular products
* Brew Rewards information
* Company story and background
* Navigation to Menu, Cart, and Rewards pages

#### How to Use

1. Open the website.
2. Browse featured products and promotions.
3. Click **Order Now** or **View Menu** to start shopping.

---

### 2. Menu Page

The Menu Page displays all available products categorized by type.

#### Available Categories

* Coffee
* Tea
* Bakery
* Merchandise

#### How to Use

1. Click **Menu** from the navigation bar.
2. Select a category from the sidebar.
3. Browse available products.
4. Click a product to view details.
5. Select **Quick Add** to immediately add the item to the basket.

---

### 3. Product Customization

Customers can customize selected beverages before adding them to their basket.

#### Available Options

* Size Selection

  * Small
  * Medium
  * Large
* Milk Options

  * Whole Milk
  * Oat Milk
  * Almond Milk
  * Skim Milk
* Add-ons

  * Extra Espresso Shot
  * Caramel Drizzle

#### How to Use

1. Open a product.
2. Choose preferred size.
3. Select milk type.
4. Add optional extras.
5. Adjust quantity.
6. Click **Add to Basket**.

---

### 4. Shopping Cart

The Cart stores all selected products before checkout.

#### Functions

* View selected items
* Modify quantities
* Remove products
* Add special instructions
* View order summary

#### How to Use

1. Click the cart icon.
2. Review selected products.
3. Adjust quantities if necessary.
4. Enter special instructions.
5. Proceed to checkout.

---

### 5. Order Summary

The system automatically calculates:

* Subtotal
* Tax
* Service Fee
* Total Amount

#### Additional Features

* Promo Code Entry
* Loyalty Progress Tracking

---

### 6. Brew Rewards System

The Rewards Page allows customers to monitor loyalty points and rewards.

#### Features

* Loyalty Bean Tracker
* Reward Progress Monitoring
* Recent Orders
* Member Status Display
* Points Redemption

#### How to Use

1. Navigate to **Rewards**.
2. View current points balance.
3. Check reward eligibility.
4. Redeem available rewards.

---

### 7. Mobile Navigation

The website supports mobile devices through a responsive menu.

#### Features

* Mobile-friendly interface
* Slide-out navigation menu
* Optimized touch controls

#### How to Use

1. Tap the menu icon.
2. Select the desired page.
3. Navigate normally throughout the website.

---

## User Workflow

### Ordering Coffee

1. Open the Home Page.
2. Navigate to Menu.
3. Select a product.
4. Customize your beverage.
5. Add the item to the basket.
6. Review the cart.
7. Apply promo codes if available.
8. Proceed to checkout.

## Troubleshooting

### Cart Not Updating

* Refresh the page.
* Ensure JavaScript is enabled.

### Images Not Loading

* Check internet connectivity.
* Refresh the website.

### Menu Not Displaying Products

* Reload the page.
* Verify browser compatibility.
